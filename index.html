Key Plan · MCP Quartet One bet, four targets

Model Context Protocol servers for Blender, Houdini, Nuke, and Natron

Four MCP servers that expose each application's Python API as structured tools an LLM can call directly. The Nuke and Houdini builds add a persistent memory layer, CLAUDE.md behavioral rules, BM25-based RAG over a growing best-practices file, and bidirectional events — so the assistant gets smarter the more you use it, instead of starting from scratch each session. blender-mcp surfaces 175 tools across 25 subsystems, houdini-mcp 166, nuke-mcp 57.

Text_Loom

Node graph for procedural editing of text with LLMs, with five front ends: TUI, GUI, REPL, API and batch.
